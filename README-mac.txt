Geo Guess for Mac
=================

This build is not signed with an Apple Developer ID. macOS will warn you the first time it opens. That warning is Gatekeeper. The warning is expected. Shape rounds work with no internet; only "Cities from space" uses the internet, to load Apple Maps satellite pictures.

1. Unzip GeoGuess-mac-universal.zip.
2. Drag Geo Guess.app into the Applications folder.
3. If macOS says the app is damaged, or that it cannot be opened, open Terminal and run:

   xattr -cr "/Applications/Geo Guess.app"

4. In Finder, open Applications. Hold the Control key and click Geo Guess. Choose Open. Click Open on the next dialog.
   If that dialog does not appear: open System Settings, go to Privacy & Security, scroll down, and click Open Anyway next to Geo Guess.

5. After that first Open, the app opens normally. Kids Computer can open it from the Geo Guess tile.

Quit with Command-Q, or close the window. The app quits completely, so the launcher can come back.

The zip is a universal app. It runs on Apple silicon and on Intel Macs. It needs macOS 14 or later.

Progress stays on this Mac. Nothing is uploaded.
